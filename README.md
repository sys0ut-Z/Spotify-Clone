# Spotify Clone

A full stack music streaming application with real-time chat, user activity, and music playback.

## 🚀 Features
- User Authentication
- Music Playback
- Album & Song Management
- Real-time Chat
- Online User Status
- Live Listening Activity

## 🛠️ Tech Stack
- Typescript
- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Socket.IO
- Clerk
